
# Gerenciador de Tarefas

##  Sobre o projeto

O Gerenciador de Tarefas é uma aplicação web desenvolvida para organizar e controlar tarefas de forma simples e prática. O usuário pode criar, visualizar e remover tarefas, mantendo tudo organizado em listas.

O projeto foi construído com JavaScript puro, focando no aprendizado de manipulação do DOM e na lógica de funcionamento da aplicação.

##  Funcionalidades

* Criar tarefas
* Remover tarefas
* Limpar campos de entrada automaticamente
* Associar tarefas a listas específicas
* Organização dinâmica das tarefas na interface

##  Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

##  Como executar o projeto

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Comece a utilizar o gerenciador de tarefas
